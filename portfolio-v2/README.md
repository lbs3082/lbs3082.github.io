# 이범수 포트폴리오 — 별도 버전

기존 루트 포트폴리오를 변경하지 않고 `portfolio-v2/`에 독립적으로 만든 정적 웹사이트입니다. 상위 폴더의 JavaScript·CSS·이미지에 의존하지 않습니다.

- 공통: `./`
- FDO·운영 순서: `./?view=fdo`
- 데이터 분석 순서: `./?view=data`
- 사례 상세: `case.html?id=rm-marketing` 등

세 보기의 사례 내용은 같으며, 대표 사례와 그 밖의 작업의 순서·분류가 달라집니다. FDO 링크에서는 보기 토글을 제거하고 메인·상세 이동에도 FDO 순서를 유지합니다. 공통·데이터 보기에는 기존 토글을 유지합니다. 모든 상세 페이지에서 메인으로 돌아갈 수 있고, 마지막 사례는 처음 사례로 순환하지 않습니다.

`content.js`에서 사례 내용을, `readingModes`에서 순서를 관리합니다. 사진과 모델 비교 자료는 제공된 자료를 사용하며, 화면의 흐름 도식은 실제 서비스 캡처와 구분해 표시했습니다.

## 반영 기준

`포트폴리오_수정안.md` 및 기존 제공 자료와 대화의 확인 내용을 사용했습니다. 수정안의 빈칸과 예시를 실제 성과로 만들지 않았습니다. SQL 사용 사례, 개인별 세부 분석 기여, PM과의 이견·합의 장면, 전후 측정 회차 등 확인되지 않은 내용은 추가하지 않았습니다.

RAG 성과·상세 프로젝트는 추가하지 않았습니다. 진행 중인 일경험은 현재 확인된 활동명·기간·역할만 소개합니다. RM의 4일 조기 완료, 스마트 침대, 근거가 없는 기여율은 이 새 버전에 표시하지 않습니다.

## 로컬 실행

이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1`을 실행하고 출력된 로컬 주소를 엽니다. 별도 설치나 빌드가 필요하지 않습니다.

상세 페이지의 범위 설명은 `scopeNotes`로 관리하고 이야기 끝의 “확인한 범위와 한계” 블록 한 곳에 모읍니다. 2026-10-21 확인한 TA 연도별 제출률 정의·교수님의 시간 단축 요청, MT 개최 연도·음주 사건 집계 기준, 4호선 회귀분석 역할을 반영했습니다. 추가 기록은 답변을 받은 뒤 반영합니다.

추가 확인: TA 두 연도 제출률 모두 부분점수 포함, MT 평균은 2023·2024년 기준, 4호선은 역별 하차 인원·역세권 500m 주변 인구 사용. 고객 군집 기반 유형 변화 예측은 본인이 설명할 수 있는 기여가 없고 공개를 원하지 않는다는 답변에 따라 모든 보기에서 제외했습니다.

추가 기록이 없다는 답변에 따라 TA의 추가 확인 예정 문장을 삭제했습니다. 확인된 수치와 비교 한계만 유지합니다. 확인되지 않은 개인 회상·미래 기록 계획을 제거하고 About과 이상거래 사례의 개인 역할/팀 평가 결과를 분명히 했습니다. 제외한 유형 변화 사례에 연결되던 LightGBM 기술 표기도 제거했습니다.

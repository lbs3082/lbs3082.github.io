# 이범수 — AI Engineer

데이터 분석과 개발 경험의 문제 발견, 판단, 실행을 소개하는 Case Study 포트폴리오입니다. 각 상세 페이지는 Problem → Insight → Strategy → Execution → Result 순서로 구성합니다.

**사이트:** https://lbs3082.github.io/

## 수정 위치

- `index.html`: 소개, 학력·경험, 연락처
- `stories.js`: 학생회·실습 조교 사례와 홈 페이지의 사례 구성
- `projects.js`: RM 대시보드·스마트 침대·양성과정 사이드 프로젝트
- `cases.js`: 사례별 핵심 질문, 인사이트, 전략, 실행 단계
- `narrative.js`: 대표 사례·5단계 상세·사이드 프로젝트 요약, 스크롤 목차, 이미지 확대
- `case-study.css`: 편집 디자인과 PC·모바일 레이아웃
- `assets/`: 웹사이트에서 사용하는 이미지

## 배포

GitHub Pages가 `main` 브랜치의 루트 폴더를 게시합니다. 빌드나 패키지 설치 없이 HTML, CSS, JavaScript를 사용하며, `.nojekyll` 파일로 Jekyll 처리를 생략합니다.

수정 사항을 `main`에 푸시하면 자동으로 반영됩니다. 로컬에서는 이 폴더에서 `python -m http.server 4173`을 실행한 뒤 `http://localhost:4173/`을 열어 확인할 수 있습니다.

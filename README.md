# 이범수 — AI Engineer

데이터 분석과 개발 경험을 소개하는 포트폴리오입니다.

**사이트:** https://lbs3082.github.io/

## 수정 위치

- `index.html`: 소개, 학력·경험, 연락처
- `stories.js`: RAG, RM 대시보드, 학생회, 실습 조교 사례
- `projects.js`: 기존 프로젝트와 사이드 프로젝트
- `github.js`: GitHub 개발 작업
- `app.js`: 프로젝트 목록·상세 페이지와 이미지 확대
- `styles.css`, `editorial.css`: 레이아웃과 반응형 디자인
- `assets/`: 웹사이트에서 사용하는 이미지

## 배포

GitHub Pages가 `main` 브랜치의 루트 폴더를 게시합니다. 빌드나 패키지 설치 없이 HTML, CSS, JavaScript를 사용하며, `.nojekyll` 파일로 Jekyll 처리를 생략합니다.

수정 사항을 `main`에 푸시하면 자동으로 반영됩니다. 로컬에서는 이 폴더에서 `python -m http.server 4173`을 실행한 뒤 `http://localhost:4173/`을 열어 확인할 수 있습니다.
